# Changelog

All notable changes to this project are documented here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [Unreleased]

### Added
- Randomize button that shows a new logo with a random two-word name, shape and colors.
- Previous button to step back through the last 20 logos.
- Download SVG button that saves the current logo as a safe, self-contained SVG file.
- Keyboard and screen reader support, including an announcement of each new logo.
- Layout that works from 320 px wide phones to wide desktop screens.
- Privacy by design: no cookies, no browser storage, no third-party requests, no tracking.
- Static hosting on Azure Static Web Apps with a strict Content-Security-Policy, HTTPS only, and a reviewed deploy workflow.
