# Upgrade dependencies

Goal: $ARGUMENTS (default: security fixes plus patch and minor updates)

## 1. Inventory
Run what applies to the repository and summarize in one table (package, current, wanted, latest, vulnerable):
- .NET: `dotnet list package --outdated`, `dotnet list package --vulnerable --include-transitive`; TargetFramework, `global.json` SDK, `Directory.Packages.props` when central package management is used.
- npm: `npm outdated`, `npm audit --omit=dev`; Angular and Node versions (`ng version`, `engines`).
- Python: `uv pip list --outdated` or `pip list --outdated`, `pip-audit` when available.
- PHP: `composer outdated`, `composer audit`.

## 2. Plan
Group the work: security fixes first, then patch and minor updates, then each major upgrade on its own. For every major upgrade read the release notes and breaking changes first (Microsoft Learn MCP for .NET, `https://angular.dev/update-guide` for Angular, Context7 or the project's changelog for the rest). Write the plan from `.claude/templates/plan.md` as `docs/specs/upgrade-YYYY-MM-DD.plan.md`. **Ask for approval**: every new or upgraded package needs it.

## 3. Execute, one step per commit
- **Angular**: `ng update @angular/core@<next major> @angular/cli@<next major>`, one major at a time; it runs the official migrations. Then the other Angular packages.
- **.NET**: update TargetFramework, `global.json` and package versions (in `Directory.Packages.props` when used); fix breaking changes. If the `dotnet-upgrade` plugin from dotnet/skills is installed, use it.
- **npm, pip, composer**: install the exact version with the package manager. Lockfiles are regenerated by the tool, never edited by hand.
- After every step: `/verify`, then commit `chore(deps): <what> <from> to <to>`.

## 4. Security pass
The **security** agent reviews the final diff with a focus on the supply chain: new transitive packages, install scripts, maintainers, typosquatting, and the audit results after the upgrade.

## 5. Report
What was upgraded, what was skipped and why, follow ups (deprecations to remove, majors to plan later).
